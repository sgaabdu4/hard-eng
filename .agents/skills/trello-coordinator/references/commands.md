# Board commands + config

Load before running the script or editing `trello.json`.

## Secrets + state

- `.env.trello.local` in the main checkout holds `TRELLO_KEY` + `TRELLO_TOKEN`. Git must ignore it; the script refuses otherwise, and `save-secret` adds it to the local `info/exclude` when needed. A worktree reads the main checkout's file through `git rev-parse --git-common-dir`; never copy it.
- Key + token = the steps in [hosts](hosts.md#missing-key-or-token). The token reaches every board of its account.
- State, posted-comment log, run lease and the coordinator's handover note (`handover.md`: card → worker thread or worktree, open promises) live in `<git common dir>/trello-coordinator/`: never tracked, shared by worktrees on one machine. One machine runs the coordinator.
- Output, errors and logs never contain the key or token.

## `trello.json`

Repository root, tracked, no secrets (a key-like value is refused).

| Field         | Meaning                                                                                                                                                                                                                                             |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `board`       | Required. Board link or shortLink.                                                                                                                                                                                                                  |
| `account`     | Optional. Trello username the token must belong to; every write is refused for another account. Left out = the token's account.                                                                                                                     |
| `allowed`     | Optional. Left out = every board member's comments are requests, so a new member needs no setup. Set = only these usernames make requests. Everyone else = information.                                                                             |
| `lists`       | Optional. Role → list name: `todo`, `doing`, `testing`, `done` required; `urgent`, `discuss` optional. Left out = found by name (To do or Backlog, Doing or In progress, Testing or Review, Done, Urgent, Discuss).                                 |
| `needsLabels` | Username → label name, for example `"Needs Sam"`.                                                                                                                                                                                                   |
| `timing`      | Defaults in brackets: `everyMinutes` (15), `chaseHours` (24), `promiseHours` (6), `doneGraceHours` (72), `quietHours` (none, for example `"22:00-07:00"`), `timeZone` (UTC, IANA name).                                                             |
| `roles`       | Optional; left out = the default split in hosts. Role → `{"model", "why"}` plus optional `"provider"` (the host's provider id, for hosts that offer several) for `coordinator`, `builder`, `planner`, `reviewer`, `lookup`, optional `computerUse`. |
| `privacy`     | Optional extra regex list blocked in comments.                                                                                                                                                                                                      |

## Commands

`python3 .agents/skills/trello-coordinator/scripts/trello.py <command>`; `<card>` = card number (`#N` name prefix) or shortLink. `--dry-run` on any write command prints the planned requests and sends nothing.

| Command                                                                                | Result                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `probe`                                                                                | JSON `account`, `board`, `lists` (role, name, id), `labels`. Exit 1 when the account differs from `account` or a configured list is missing.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `check`                                                                                | Starts the run lease and prints the JSON report below with its `runId`; never writes to Trello. Lease held (younger than 2 × `everyMinutes`) → prints `{"skipped": true}`, reads nothing; end the run without `finish`. After a full read it saves the time the read began, which the next `check` uses as `since`. Exit 1 + `error` when the read is incomplete, including network failures.                                                                                                                                                                                     |
| `finish <runId>`                                                                       | Ends the run lease only when it still belongs to that run. Run it last in every run that was not skipped.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `save-secret TRELLO_KEY\|TRELLO_TOKEN <file>`                                          | Saves the value in that file to `.env.trello.local` in the main checkout, readable by its owner only; replaces an older value of the same name. Refuses an empty value, a value with spaces, or a file git does not ignore. Prints the name only. Needs no key or token.                                                                                                                                                                                                                                                                                                          |
| `comment <card> <text-file> [--image PATH ...]`                                        | Uploads images (repeat `--image` or list several paths), posts one new comment with them, logs its id. Refuses email addresses, phone numbers and `privacy` matches anywhere in the final comment, image names included. Refuses walls of text (see Core rules). Never edits. Asks a question of a tagged member → makes them a card member and, for an `@name` in `needsLabels`, adds that label. On a `testing` card, text that says it waits on us and is not live also moves the card to the top of `doing`.                                                                  |
| `move <card> <role> [--proof PATH ...] [--shows TEXT] [--check TEXT] [--comment FILE]` | Moves to the top of the role's list. `testing` needs `--comment FILE` that tags a board member, and at least one proof image (`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`) with one `--shows` per image (the change it shows, used as the image's name, privacy-checked), or `--check TEXT` (what to try) for work with no screen. It posts one comment (the text, the `To try:` note, the images), makes each tagged member a card member and adds their `needsLabels` label. `testing` and `done` are refused while checklist items are open. `done` removes `needsLabels` labels. |
| `new <role> <title> [--description-file PATH]`                                         | Creates a card at the top of the role's list, named `#N <title>` with the next free number (archived cards count). Same privacy and layout refusals as `comment`. Prints the number and link.                                                                                                                                                                                                                                                                                                                                                                                     |
| `member <card> add\|remove <username>`                                                 | Adds or removes one board member on the card; a username not on the board is refused.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `tick <card> <item> [--undo]`                                                          | Marks one checklist item done (`--undo`: open). The item text matches exactly, else as part of the name; no match or two matches is refused.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `label <card> add\|remove <label>`                                                     | Adds or removes one label by name; adding `Waiting for real case` creates it on the board when missing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `card <card>`                                                                          | Prints the card's name, list, labels, members, checklists with item states, due date, description, every comment (author, date, text) and attachments (id, name, url, date). Read-only.                                                                                                                                                                                                                                                                                                                                                                                           |
| `update <card> [--name TEXT] [--due ISO] [--renumber]`                                 | Renames the card or sets its due date. `--renumber` names it `#<next free number> <title>`; use it on a card without a number or a copy that repeats one.                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `upload <card> PATH ...`                                                               | Attaches files; prints attachment ids + Markdown image lines.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `detach <card> <attachment-id> ...`                                                    | Deletes the named attachments, for example an outdated mockup.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `download <card> [--since ISO] [--dir DIR]`                                            | Saves the card's attachments added since a time; prints paths.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

Rate limit: a 429 waits for the time the rate headers allow, then retries. The key and token go only to `api.trello.com`; a redirect elsewhere is followed without them.

## `check` report

Each list holds `{card, name, list, url, at, author, excerpt}` items. "Our comment" = a comment whose id is in the posted log.

| Field         | Item                                                                                                                                                                                                                                                                                                                                                                   |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `requests`    | Newest action after our newest comment is a comment (an edited comment counts at its edit time), image, description edit, card move or new card by a board member, or an `allowed` member when set. A short "ok" or "thanks" on a card in `done` is no request. Any age, on every open card; a card in `done` counts only until `doneGraceHours` after its move there. |
| `information` | Same, by anyone else. Never a request.                                                                                                                                                                                                                                                                                                                                 |
| `owner`       | Newest action on the card is a comment, move or new card by the token's account that is not in the posted log (our `move` and `new` log theirs) and is newer than this machine's first `check`: the human owner. Stays listed until we reply. Act on it; never write over it.                                                                                          |
| `promises`    | Our newest comment says "I will", "I'll", "Next:", "I am building", "I am changing" or "being built" in text after its last "is live", "are live", "went live" or "is done" ("when it is live" still counts as a promise), and is older than `promiseHours`.                                                                                                           |
| `silent`      | An open question of ours is older than `chaseHours`, counted from that question's date, not from our newest comment. Never for a person whose label is on a `testing` card (see `testQueue`).                                                                                                                                                                          |
| `buried`      | Open question of ours to a person that our newest comment does not tag again: ask it again in a new tagged comment.                                                                                                                                                                                                                                                    |
| `badTags`     | `@name` in our comments that is not a board member.                                                                                                                                                                                                                                                                                                                    |
| `labels`      | `needsLabels` label with no open question to that person, or an open question with no label. Open question = any comment, ours or a board member's, that tags another member and asks something (`?`, please, reply, can you, could you, let me know), with no comment from that member after it.                                                                      |
| `waitsOnUs`   | Card in `testing` whose newest comment of ours says it waits on us ("next release", "not built yet", "I am fixing", "I am building", "I am changing", "I will fix", "being built", "waits for the #N fix") and does not say it is now live; "when it is live" still waits.                                                                                             |
| `testQueue`   | One item per person whose `needsLabels` label is on cards in `testing`: the count of those cards and the oldest one. Not chased on the cards.                                                                                                                                                                                                                          |
| `unnumbered`  | Open card whose name lacks `#N`, or the newer of two open cards with the same `#N`. A `#N` that matches two cards is refused by every command: use the shortLink.                                                                                                                                                                                                      |
| `overdue`     | Due date passed, card not in `done`.                                                                                                                                                                                                                                                                                                                                   |
| `realCases`   | Open card with the `Waiting for real case` label: only a real user event can prove it.                                                                                                                                                                                                                                                                                 |
