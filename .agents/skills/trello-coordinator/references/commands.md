# Board commands + config

Load before running the script or editing `trello.json`.

## Secrets + state

- `.env.trello.local` in the main checkout holds `TRELLO_KEY` + `TRELLO_TOKEN`. Git must ignore it; the script refuses otherwise, and `save-secret` adds it to the local `info/exclude` when needed. A worktree reads the main checkout's file through `git rev-parse --git-common-dir`; never copy it.
- Key + token = the steps in [hosts](hosts.md#missing-key-or-token). The token reaches every board of its account.
- State, posted-comment log, run lease and the coordinator's handover note (`handover.md`: card → worker thread or worktree, open promises) live in `<git common dir>/trello-coordinator/`: never tracked, shared by worktrees on one machine. One machine runs the coordinator.
- Output, errors and logs never contain the key or token.

## `trello.json`

Repository root, tracked, no secrets (a key-like value is refused).

| Field         | Meaning                                                                                                                                                                                                                                             |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `board`       | Required. Board link or shortLink.                                                                                                                                                                                                                  |
| `account`     | Optional. Trello username the token must belong to; every write is refused for another account. Left out = the token's account.                                                                                                                     |
| `allowed`     | Optional. Left out = every board member's comments are requests, so a new member needs no setup. Set = only these usernames make requests. Everyone else = information.                                                                             |
| `lists`       | Optional. Role → list name: `todo`, `doing`, `testing`, `done` required; `urgent`, `discuss` optional. Left out = found by name (To do or Backlog, Doing or In progress, Testing or Review, Done, Urgent, Discuss).                                 |
| `needsLabels` | Username → label name, for example `"Needs Sam"`.                                                                                                                                                                                                   |
| `timing`      | Defaults in brackets: `everyMinutes` (15), `chaseHours` (24), `promiseHours` (6), `doneGraceHours` (72), `quietHours` (none, for example `"22:00-07:00"`), `timeZone` (UTC, IANA name).                                                             |
| `roles`       | Optional; left out = the default split in hosts. Role → `{"model", "why"}` plus optional `"provider"` (the host's provider id, for hosts that offer several) for `coordinator`, `builder`, `planner`, `reviewer`, `lookup`, optional `computerUse`. |
| `privacy`     | Optional extra regex list blocked in comments.                                                                                                                                                                                                      |

## Commands

`python3 .agents/skills/trello-coordinator/scripts/trello.py <command>`; `<card>` = card number (`#N` name prefix) or shortLink. `--dry-run` on any write command prints the planned requests and sends nothing.

| Command                                         | Result                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `probe`                                         | JSON `account`, `board`, `lists` (role, name, id), `labels`. Exit 1 when the account differs from `account` or a configured list is missing.                                                                                                                                                                                                                                                  |
| `check`                                         | Starts the run lease and prints the JSON report below with its `runId`; never writes to Trello. Lease held (younger than 2 × `everyMinutes`) → prints `{"skipped": true}`, reads nothing; end the run without `finish`. After a full read it saves the time the read began, which the next `check` uses as `since`. Exit 1 + `error` when the read is incomplete, including network failures. |
| `finish <runId>`                                | Ends the run lease only when it still belongs to that run. Run it last in every run that was not skipped.                                                                                                                                                                                                                                                                                     |
| `save-secret TRELLO_KEY\|TRELLO_TOKEN <file>`   | Saves the value in that file to `.env.trello.local` in the main checkout, readable by its owner only; replaces an older value of the same name. Refuses an empty value, a value with spaces, or a file git does not ignore. Prints the name only. Needs no key or token.                                                                                                                      |
| `comment <card> <text-file> [--image PATH ...]` | Uploads images (repeat `--image` or list several paths), posts one new comment with them, logs its id. Refuses email addresses, phone numbers and `privacy` matches anywhere in the final comment, image names included. Never edits.                                                                                                                                                         |
| `move <card> <role> [--proof PATH ...]`         | Moves to the top of the role's list. `testing` needs at least one proof image (`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`), uploaded first. `done` removes `needsLabels` labels.                                                                                                                                                                                                                |
| `label <card> add\|remove <label>`              | Adds or removes one label by name.                                                                                                                                                                                                                                                                                                                                                            |
| `card <card>`                                   | Prints the card's name, list, labels, due date, description, every comment (author, date, text) and attachments (id, name, url, date). Read-only.                                                                                                                                                                                                                                             |
| `update <card> [--name TEXT] [--due ISO]`       | Renames the card or sets its due date.                                                                                                                                                                                                                                                                                                                                                        |
| `upload <card> PATH ...`                        | Attaches files; prints attachment ids + Markdown image lines.                                                                                                                                                                                                                                                                                                                                 |
| `detach <card> <attachment-id> ...`             | Deletes the named attachments, for example an outdated mockup.                                                                                                                                                                                                                                                                                                                                |
| `download <card> [--since ISO] [--dir DIR]`     | Saves the card's attachments added since a time; prints paths.                                                                                                                                                                                                                                                                                                                                |

Rate limit: a 429 waits for the time the rate headers allow, then retries. The key and token go only to `api.trello.com`; a redirect elsewhere is followed without them.

## `check` report

Each list holds `{card, name, list, url, at, author, excerpt}` items. "Our comment" = a comment whose id is in the posted log.

| Field         | Item                                                                                                                                                                                                                                      |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `requests`    | Newest action after our newest comment is a comment, image or description edit by a board member, or an `allowed` member when set. Any age, on every open card; a card in `done` counts only until `doneGraceHours` after its move there. |
| `information` | Same, by anyone else. Never a request.                                                                                                                                                                                                    |
| `owner`       | Newest action on the card is a comment by the token's account that is not in the posted log and is newer than this machine's first `check`: the human owner. Stays listed until we reply. Act on it; never write over it.                 |
| `promises`    | Our newest comment says "I will", "I'll" or "Next:", does not say the work is now live or done ("when it is live" still counts as a promise), and is older than `promiseHours`.                                                           |
| `silent`      | Our last comment asks a question (`?`, please, reply, can you, could you, let me know) of a tagged or labelled person, and nobody answered for `chaseHours`.                                                                              |
| `badTags`     | `@name` in our comments that is not a board member.                                                                                                                                                                                       |
| `labels`      | `needsLabels` label with no open question to that person, or an open question with no label. Open question = our last comment tags the person and asks a question as in `silent`.                                                         |
| `waitsOnUs`   | Card in `testing` whose newest comment of ours says it waits on us ("next release", "not built yet", "I am fixing") and does not say it is now live; "when it is live" still waits.                                                       |
| `unnumbered`  | Open card whose name lacks `#N`.                                                                                                                                                                                                          |
| `overdue`     | Due date passed, card not in `done`.                                                                                                                                                                                                      |
