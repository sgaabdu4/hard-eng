# Direct Questioning

1. Accepted outcome unstated → settle it as the first frontier; it bounds every later decision.
2. Convert request → bounded decision inventory; exclude objective facts evidence can settle; rule beyond-outcome items `out-of-scope`.
3. Apply `SKILL.md` Admission → classify each item + resolve objective gaps/contradictions.
4. Select next dependency frontier by impact → batch every independent material decision → render one `SKILL.md` decision set → wait once.
5. Recompute inventory after every answer/correction → graduate every `unspecifiable` item the answer sharpened → repeat by frontier until `SKILL.md` Return gate passes.
