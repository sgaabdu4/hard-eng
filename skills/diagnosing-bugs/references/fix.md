# Fix

1. Confirm explicit fix authority + preserved red reproduction + proven root owner/mechanism + blast radius.
2. External dependency/runtime/platform behavior → `research` primary-source `PASS` + bind resolved local version/tool/path before selecting or editing the solution.
3. Change root owner + connected blast radius; remove workaround/duplicate behavior introduced by the defect.
4. Use `test-quality` for the smallest public regression seam; intended defect must make it red + restored behavior green.
5. Interpreter/compiler/runner defect → actual compatible tool execution; source-text/substring/static checks prove wiring only.
6. Rerun original reproduction + regression proof at the observed public/package/release boundary when applicable.
7. Unexpected result or contract-surprise → return to diagnosis + audit adjacent assumptions across syntax, cardinality, quoting, paths, waits, job boundaries, platform, version, and state.
8. Before paid/native retry → `deterministic-checks` retry-readiness PASS; independent cheap checks parallel + prerequisite failure cancels dependent work.
9. Use `deterministic-checks` for every applicable final gate; report commands + exits + unresolved evidence.

- Fix completion = original proof green + regression proof red-capable/green-after + connected gates pass.
- Exact-line correction without adjacent-assumption audit + compatible real-tool sentinel = incomplete.
- Gate/reproduction unavailable = `CONCERNS` or `FAIL` with exact gap; never weaken or suppress proof.
