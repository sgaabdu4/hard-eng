# Mutation Ledger

1. Owner = `scripts/mutation_ledger.py` + committed root `mutation-ledger.json`; one row per function keyed `<path>::<qualname>` + AST source hash; a function whose row hash matches its current source is never scored again; formatting-only edits keep the row.
2. Scope = functions with no current row; `plan` lists them, `--changed-only`/`--base <ref>` narrows to files changed against the merge base (`--base` → `MUTATION_LEDGER_BASE` → `@{upstream}` → `origin/main|develop`; none = FAIL, never an empty scope).
3. Runner = mutmut for Python (`pyproject.toml` `[tool.mutmut]` = source paths + `do_not_mutate`; test files never enter scope); JS/TS + Dart = no ledger runner yet → `runners=none` printed + brief `deferred` row when the repository needs one; first wiring per repository = `research` PASS on the runner's current CLI contract.
   - Hard Eng = `requirements-mutation.txt` → `scripts/mutation-venv.sh` builds ignored `.venv-mutation`; tests = `tests/` under `HARD_ENG_INPROCESS=1`; `run` removes the stale `mutants/tests` copy first.
4. Public repository = `.github/workflows/mutation-nightly.yml` (`schedule` on the default branch, free standard runner, `workflow_dispatch` for a manual run): `gh api` visibility → private = exit without scoring; public = toolchain + `mutation_ledger.py run --budget-minutes 300` → one `mutmut run` over every unscored pattern → rows for every function whose mutants all finished; unfinished functions wait for the next night → branch `mutation-ledger/nightly` + `gh pr create` against the default branch (needs the repository setting that lets Actions create pull requests).
5. Private repository = local before push: `scripts/mutation-venv.sh` → `python3 skills/deterministic-checks/scripts/mutation_ledger.py run --repo . --changed-only --budget-minutes <N>`; nightly runs on private repositories or paid runners = forbidden.
6. Survivor = mutant with exit code survived OR no test reaching it; recorded as `needs-verdict` + `since` date; `verdict --function <key> --mutant <name> --verdict fixed|equivalent|invalid|deferred --reason <why>` closes it (`test-quality` judgment; kill score alone = insufficient); `record --verdicts <json>` applies verdicts at record time.
7. Gate family `mutation-ledger` = `check --repo .` in the `publish` push phase + CI (`MUTATION_LEDGER_BASE` = CI comparison base, `MUTATION_LEDGER_VISIBILITY` = `github.event.repository.private`; local = `gh repo view`, unknown = private): ledger shape valid + no `needs-verdict` row older than seven days + private repository: every changed function has a current row (public = PASS, `unscored=<n>` printed for the nightly job); mutation run inside push or pull-request CI = forbidden.
8. Deterministic `PASS` = the file says so; rows are never typed by hand: `record` reads `mutants/<file>.meta` totals per mutant key (`<module>.x_<function>__mutmut_N`, methods `<module>.xǁ<Class>ǁ<method>__mutmut_N`).
