# Learning Workflow

1. Read source evidence → reject duplicate, one-off, inferred-only, preference-only candidate.
2. Recurrence claim → `repeated-failure-learning`; otherwise verify correction/false gate/systemic boundary gap/manual waste.
3. Record accepted learning = failure + `Verified` evidence + root class + prevention owner + required proof.
4. Select narrowest durable owner:

   `root invariant/schema/code + regression test → scanner/lint/hook/CI → script/tool → skill/route → docs/runbook`

5. Mechanically detectable gap → executable prevention + violating fixture + valid fixture + actual-seam proof; prose may route but cannot be the only control.
6. Place proof before the expensive boundary; parallelize independent cheap checks + cancel dependent work on failure.
7. Classify urgency:
   - continued work risks protected boundary → pause affected product path + repair/decision now;
   - all other learning → assign destination + keep product lifecycle moving; execution follows global Subagents contract.
8. Destination repair uses normal direct/`he` route + its own approvals; source PLAN remains available and unpaused.
9. Run affected regression + deterministic proof at destination.
10. Resolve = prevention revision + proof; deferred = owner + next action; no candidate = `PASS: no learning action`.
