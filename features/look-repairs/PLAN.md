# Look repairs from develop to main, without the whole-project UI scan

Status: Complete

## Outcome + scope

Installed projects on `main` get the `look` repairs that develop holds: element facts with kind tags, exact keys, code verdicts for measured items, weight and align facts, the fixed gap order, the stale image refusal and the earlier-item lists. New on `main` beyond the measured-fact repairs: the kind-tag, key and stale-image refusals, the count guard of `look_answer.py` (the earlier hotfix left it out), the first verdict kept at a head, a Fail item with a leading frame and the `Recheck` line forms of `look_answer.py`, and one reviewer rule sentence: the Alignment line about a field action being an icon inside its field (develop `19a9e291`). The coordinator can cut it with its test. Scope cut: code decides only whether the stated observation is true (square or rounded corners, touch or apart, centred or start, tap size, text size, and a claim that one element is bolder or lighter than another). Code never fails a value only because a `DESIGN.md` token list lacks it, since those lists are complete only once develop's whole-project scan enforces them. An item whose only claim is "not a token" goes to the reviewer as judgement, as on `main`, so it can be disputed. The facts list prints no colour value and no gap or radius value for the reviewer to copy as an item. A gap fact is recorded only between neighbours on one line or one stack with nothing between them but their own spacing. The judgement recheck of develop is in: a disputed Fail goes to an evidence re-review of the item (`look_dispute.py`), a claim about a keyed element is checked in code in the direction of the claim, each corner of a control or chip is recorded. Non-goals: the whole-project HE-UI-SOURCE pass and its modules, the strict `AGENTS.md` changes, the request hold and everything that depends on it (route init script, session cap, idle limit), the wrapped-label rule, the masked-document check, every code verdict from a `DESIGN.md` token list (colour, spacing and rounded tokens), and every other develop change. The judgement recheck of develop is in, see below.
